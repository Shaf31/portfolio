# Elshafey Ahmed portfolio

Static HTML, CSS and vanilla JS, published by GitHub Pages from `main` at https://shaf31.github.io/portfolio/.

## Structure
- `index.html`: landing page ("Two Personalities One Destination"). Links to the two versions and to `contact-me.html` (black, minimal contact page).
- **Bold** (neobrutalist): `home.html`, `about.html`, `work.html` + `work-<sector>.html`, `experience.html`, `skills.html`, `contact.html`. Styles in `style.css`, theme in `theme.js`.
- **Calm** (minimal): the same pages inside `calm/`, styles in `calm/v2.css`.
- Work images: `assets/work/hd/full` (up to 2400px) and `assets/work/hd/thumb` (720px), listed in `assets/work/hd/manifest.json`. Client marks: `assets/clients/`.

## Rules from the owner
- Any change made to one version must also be made to the other, adapted to that version's own style and layout.
- Push only when the owner asks.
- Visible copy uses no dashes. Never invent clients, metrics or testimonials.
- Dark mode is pitch black in both versions.
